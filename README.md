# MVTV Web App

MVTV Web App is a full-stack web application that provides users with a seamless platform to explore and interact with TV show and movie details. The app fetches data from **TMDB (The Movie Database)** and showcases it dynamically on the frontend. It includes powerful features such as search functionality, categorization, trending sections, detailed information pages, and even trailer previews.

---

## Features

### Core Functionalities
1. **Home Page**:
   - Displays categorized sections like "Trending Movies" and "Popular Movies."
   - Includes a navigation bar for easy access to different sections.

2. **Search Functionality**:
   - Users can search for movies, TV shows, or actors using the search bar.
   - Results are displayed dynamically.

3. **Categorization**:
   - Data is categorized into:
     - **Movies**
     - **TV Shows**
     - **People/Actors**
   - Additional filters for trending shows and monthly highlights.

4. **Detailed Movie/TV Show Page**:
   - Displays:
     - Release date
     - Ratings
     - Director and producer details
     - Cast and crew information
     - Short description of the movie/show
     - Links to platforms like Netflix, Amazon, Hulu, etc., where the content can be watched or purchased.
   - Option to watch the trailer directly on the app.

5. **Loading Effect**:
   - A smooth loading animation is displayed while data is being fetched.

6. **Responsive Design**:
   - Optimized for desktops and web platforms, with responsive elements for visual enhancements.

7. **Error Handling**:
   - Includes a "Page Not Found" error page for invalid routes.

---

## Tech Stack

### Frontend
- **React.js**: Component-based architecture for dynamic UI.
- **React Icons**: For visually appealing icons across the app.
- **Tailwind CSS**: Responsive and modern styling.
- **Axios**: For efficient API requests and data fetching.
- **Redux**: State management for handling complex interactions and data flow.

### Backend
- **TMDB API**: Data source for movies, TV shows, and actor details.
